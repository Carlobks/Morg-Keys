# 0002 — Repositório público "Morg Keys", sem marca nem dados pessoais

- **Estado:** aceite (2026-10-22)
- **Contexto:** o projeto nasceu para os PCs da empresa (logótipo e nome SXP, caminhos e rede pessoais). O
  utilizador quis publicá-lo no GitHub (conta Carlobks).
- **Decisão:** publicar uma **cópia limpa** em `Morg-Keys` (repositório público github.com/Carlobks/Morg-Keys),
  sem a marca SXP em nenhum sítio (textos, nomes internos `Sxp*`, pasta `sxp-arranque`, animação do logótipo),
  sem SSID nem caminhos pessoais; a pasta da empresa ficou fora do git. Licença **GPL-3.0** (o cliente do Zebar
  incluído é GPL-3.0). Commits com o e-mail noreply do GitHub.
- **Consequências:** a animação por omissão passa a ser Café. Desde 2026-10-23 o Morg Keys substitui a versão
  da empresa neste PC. Pesquisa: `docs/pesquisa/licencas-publicacao.md`.
