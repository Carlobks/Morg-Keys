# Registar decisões (ADR — Architecture Decision Records)

Pesquisa de 2026-10-23. Formato de Michael Nygard:
https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions

- Um ficheiro por decisão, numerado, uma a duas páginas: **Título**, **Contexto**, **Decisão** ("Vamos…"),
  **Estado** (proposta, aceite, substituída), **Consequências**.
- Os números nunca se reutilizam; uma decisão revertida não se apaga: fica "substituída por NNNN".
- Uso aqui: `docs/decisoes/NNNN-titulo-curto.md`. As decisões fixas (antigo §1, agora `docs/decisoes/0001`) e as
  decisões tomadas nesta sessão (pacote único do Zebar, escolher-e-enviar em vez de arrastar, download dos
  instaladores, GPL-3.0, sem marca SXP) são as primeiras candidatas.
